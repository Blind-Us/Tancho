# Tancho V3 squat_kd1_r16_400：部署規格

原地站立（輪里程保持位置），按 **LT 收左腳**、**RT 收右腳**，按住 **Shift / J 兩腳蹲下**，放開後慢慢站回。沒有跳，也沒有前進或轉向，速度命令固定是 0。
policy 負責平衡；抬腳和蹲下的動作本身由 Pi 播放偏移，跟 policy 輸出相加後送給腿馬達。

| 項目 | 值 |
|---|---|
| 訓練任務 / run | `TanchoV3-StationSquatKd1Lat-v0`，`logs/rsl_rl/tancho_v3_station_skills/2026-11-21_19-13-17_9202dff`，第 400 iter（`train/model_400.pt`） |
| 檔案 | `policy.pt`（TorchScript）、`policy.onnx`；SHA256 在 `SHA256SUMS` |
| 控制頻率 | 50 Hz |
| 腿的範圍 | 標稱 ±0.6 rad |
| **輪馬達** | DM-H3510 速度模式，**Kd = 1.0**（以前的版本是 4），扭力上限 0.45 N·m |
| 腿馬達 | DM-J4310 位置模式，Kp 20、Kd 0.2，12.5 N·m |

## 輸入 `obs`：float32 [1, 34]

| index | 內容 | 換算 |
|---|---|---|
| 0–2 | IMU 重力方向（IMU 座標，直立時 = (0, −1, 0)） | ×1 |
| 3–5 | IMU 角速度 rad/s | ×0.25 |
| 6–8 | 速度命令 (vx, vy, yaw) | **固定 0, 0, 0** |
| 9–10 | 左、右輪速 rad/s | ×0.05 |
| 11–16 | 上一步的 action（clip 後，不含偏移表） | ×1 |
| 17–20 | 腿角 − 標稱 (thigh_L, calf_L, thigh_R, calf_R)，標稱 (−0.50, +0.87) | ×1 |
| 21–24 | 腿速 rad/s | ×0.05 |
| 25–26 | LT、RT 按住 | 0 / 1 |
| 27–28 | 左、右抬腳開始後經過的時間 | min(phase, 0.6) / 0.6；閒置 = 1 |
| **29–30** | **左、右輪里程** | 2 · clip(0.03614 · (q_wheel − q_wheel_hold), −0.5, 0.5)；q_wheel 是多圈編碼器角度 rad |
| **31** | 蹲下鍵按住 | 0 / 1 |
| **32** | 蹲下深度 level | 按住時每步 +0.02 / 0.35（上限 1），放開歸 0 |
| **33** | 放開後經過的時間 | min(t_release, 0.6) / 0.6；閒置 = 1 |

**保持點**：開機（或想重設原點時）記下 `q_wheel_hold = q_wheel`，obs 29–30 就會從 0 開始。

## 每一步（0.02 s）

1. **抬腳**：規則同 hop v2 的 `DEPLOY.md`（按下的上升緣開始 0.4 s 動作；動作中的新按鍵排隊）。**不要同時送 LT 和 RT**，這版沒有訓練小跳。
2. **蹲下**：
   ```
   if 按住 and not held_prev and t_release < 0.3:   # 新規則：還在站起來就不理新的蹲下
       按住 = False
   if 放開 (held_prev and not 按住): release_level = level; t_release = 0
   else: t_release += 0.02
   level = min(level + 0.02/0.35, 1) if 按住 else 0
   ```
   腿偏移（兩腳相同，thigh / calf）：按住時 `level · (−0.305, +0.75)`；放開後 `release_level · (−0.305, +0.75) · max(0, 1 − t_release / 0.28)`。
3. 組 obs → 跑 policy → **clip 到 [−1, 1]**。
4. 腿目標 = 標稱 + 0.6·a[0:4] + 抬腳偏移 + 蹲下偏移；輪目標速 = 52.36·a[4:6] rad/s。
5. 存 clip 後的 a 當作下一步的 obs 11–16。

`reference_io.json`：8 組輸入和輸出，用來確認 ONNX 載入正確。

## 驗證（模擬）

| 測試 | 結果 |
|---|---|
| MuJoCo 按鍵組合 990 種（單按、左右交替、連蹲、蹲完抬腳、間隔 0.15–1.5 s、按住 0.1–1 s、延遲 10 / 20 ms、加感測雜訊） | 加了 0.3 s 蹲下冷卻規則：**倒 0 / 990**，最大傾角 28°；沒有冷卻規則：倒 6 次（全部是放開後 0.15 s 又按蹲下） |
| 同上，並在按鍵過程中隨機被推 ±0.5 m/s | 倒 48 / 990（4.8%）。**抬著腳的時候被推是主要的倒地原因** |
| Isaac：雜訊 + 20 ms，站 60 s / 推 0.5 / LT、RT、蹲下 ×4 | 都不倒；站立漂 18.5 cm |
| 0–2 cm 凹凸地 | 不倒，漂 6–11 cm |
| 斜坡 | 不倒，**但會溜**（Isaac +5° 漂 3.2 m） |

## 上實機前

- 第一次先架高讓輪子懸空：確認 LT / RT / 蹲下動的是哪一隻腳、方向對不對，也確認輪子正轉時輪里程是正的。
- 放到平地後依序測：站 60 s → 用手輕推 → LT → RT → 蹲下。
- 不要在抬腳或蹲下的過程中推它，也不要上斜坡。
- 位置精度預期 10–20 cm。

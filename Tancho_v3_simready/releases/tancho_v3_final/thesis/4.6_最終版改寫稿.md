# 4.6 RL 策略測試結果（最終版，2026-11-23）草稿

> 給下一版論文用。數字取自 `releases/tancho_v3_final`（StationFinal 接續 TrackHold 第 200 iter）。表格見 `../THESIS_TABLE.md`，圖檔放在同一資料夾。原稿 4.6 的 Stability 策略結果全部改成本版。

## 4.6.1 策略與測試條件

最終策略在同一個網路中完成以下動作：零命令時原地保持（以輪里程定點）、前後速度命令 ±1.2 m/s、偏航 ±1.5 rad/s、左右單腳收腳、雙腳小跳，以及深蹲（底盤最低點離地 10.7 cm）。輸入為 34 維，輪端速度迴路阻尼改為 1.0 N·m·s/rad，訓練時加入 10–20 ms 致動延遲、感測雜訊、增益與質心隨機化，並有一半的地形為 0–2 cm 凹凸地。

測試在 Isaac Sim 中進行，條件與 4.1 節 LQR 相同（物理 200 Hz、策略 50 Hz、輪端力矩 ±0.45 N·m；俯仰相對平衡角達 15°，或輪以外的部位觸地，即判為失敗）。每一項都做兩組：標稱，以及「感測雜訊 + 20 ms 致動延遲」，後者用來模擬部署條件。

## 4.6.2 初始俯仰偏差（圖 fig_final_pitch10）

±1° 至 ±10° 共十個案例，兩組條件下都未失敗。±10° 的最大水平位移為 12.8 / 6.6 cm，LQR 為 16.9 cm。但站立時有小幅持續晃動（50 Hz 下峰對峰 1.4–2.1°），所以以 ±1° 定義的恢復時間約 3.4–4.7 s，明顯比 LQR 的 0.176 s 長；加上雜訊與延遲時，沒有收斂到 ±1° 以內。

## 4.6.3 速度命令（圖 fig_final_cmd）

原稿的 Stability 策略在三種命令下都會傾倒，本版三種都未失敗：0.3 m/s 時實際約 0.25 m/s；1.0 rad/s 時約 1.07 rad/s；0.2 m/s + 0.5 rad/s 時約 0.19 m/s 與 0.33 rad/s；最大俯仰偏差 3.2–4.2°。加上雜訊與延遲時，結果幾乎相同。高速時追蹤較好：在 MuJoCo 中命令 1.2 m/s 時實跑 1.14 m/s。

## 4.6.4 50 ms 推力（圖 fig_final_push）

標稱條件下 36 N 通過。38、39 N 時俯仰短暫達 15°，依定義判為失敗，但機身未觸地並回到穩態；40、42 N 未失敗，45 N 起才真正傾倒。依失敗定義，分界略低於 LQR 的 38 / 39 N。加上雜訊與延遲後，分界為 36 / 38 N。

## 4.6.5 降低控制頻率

標稱條件下，+5° 與 +10° 在 16.7 Hz 時仍未失敗，12.5 Hz 失敗；加上雜訊與延遲後，最低可到 25 Hz。

## 4.6.6 部署條件下的動作驗收

- MuJoCo 中，在行進命令下隨機按出 990 種按鍵組合（含小跳、蹲下）：1 次傾倒。按鍵過程中再隨機推 ±0.5 m/s：倒地率 0.7%。
- Isaac 中，零命令站立 60 s 六次：漂移 12–18 cm，都不倒；MuJoCo 中為 15–27 cm。0.3 m/s 行進中與原地的收腳、小跳、蹲下也都不倒，小跳時兩輪離地 30–32 mm。

## 4.6.7 小結與限制

與 LQR 相比，本版 RL：
- 能夠行進、轉向，並做出收腳、小跳、深蹲等 LQR（固定腿部）做不到的動作；
- 初始偏差下的位移較小，50 ms 推力的分界相近（36–38 N）。

但仍有以下限制：
- 站立時的持續小幅晃動讓恢復時間較長；
- 斜坡上會下滑；
- 定點精度約 10–30 cm，達不到 LQR 的水準。

實機結果待填入表中的「實機部署」欄。

## 和 hop_dr 的差別（部署要注意）

- **腿的比例改成 ±1.0 rad**（hop_dr 是 ±0.6）：腿目標角 = 標稱 + 1.0 × a + 偏移表。輸入輸出維度、順序和 hop v2 相同（29 → 6）。
- **單側按鍵的偏移表換成 `step_lift_table.csv`**（0.06 s 抬到 +55 mm、0.12 s 往前 +50 mm、0.18 s 放在 +30 mm、0.32 s 回標稱）；LT+RT 同時按仍用 hop v2 的小跳表。按鍵排隊規則相同。
- **怎麼按**：朝台階斜約 10° 以 0.3–0.4 m/s 開過去，**先碰到邊緣的那個輪子**快碰到時（< 1.5 cm）按那一側（左輪 LT、右輪 RT），另一側在 0.3 s 後輪到它碰到時再按。
- **平地亂按會倒**：618 種平地按法壓力測試倒地 84%（`flat_press_sweep.json`），hop_dr 是 0.8%。這版只在上台階時用；平地抬腳/小跳用 hop_dr。

## 還沒做到 / 風險

- 3 cm 成功率還很低（4/32 不倒），只在特定速度與角度成立。
- 模擬裡「碰到邊緣就按」靠地形掃描，實機要靠人按，時機誤差會讓成功率更低。
- 沒有在延遲 20 ms、增益 0.8 下單獨測上台階（訓練時有隨機化）。
- 腿用到標稱 ±0.82 rad，實機要確認不會撞到機身、線材。

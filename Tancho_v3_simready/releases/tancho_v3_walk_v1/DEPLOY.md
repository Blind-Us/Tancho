# Tancho V3 walk v1 — 部署規格

6-DOF（兩腿各 2 關節 + 兩輪）依命令行走的 policy。

| 項目 | 值 |
|---|---|
| git tag | `walk-v1`（訓練 commit `5b6a164`） |
| 訓練 run | `logs/rsl_rl/tancho_v3_walk/2026-10-06_15-02-25_5b6a164` |
| 起點 | 站立 `tancho_v3_stand/2026-10-06_09-22-02_996ea2d/model_final.pt`（`--init_checkpoint`） |
| 檔案 | `policy.onnx`（opset 18）、`policy.pt`（TorchScript），兩者輸出差 < 2e-6；SHA256 見 `SHA256SUMS` |
| 控制頻率 | **50 Hz**（每 0.02 s 跑一次 policy）；模擬內馬達迴路 200 Hz |

## 輸入 `obs`：float32 [1, 25]

觀測正規化已經包在模型裡，**直接餵原始值 × 下表的 scale**，不要再自己正規化。

| index | 內容 | scale | 直立靜止時的值 |
|---|---|---|---|
| 0–2 | IMU 量到的重力方向（單位向量，IMU 座標） | 1 | (0, −1, 0) |
| 3–5 | IMU 陀螺儀角速度 rad/s（IMU 座標） | 0.25 | 0 |
| 6–8 | 速度命令 (vx m/s, vy=0, yaw rate rad/s) | 1 | 0 |
| 9–10 | 輪速 rad/s：左、右 | 0.05 | 0 |
| 11–16 | 上一步的 action（clip 後的 6 維，順序同輸出） | 1 | 0 |
| 17–20 | 腿角度 − 標稱角度 rad：thigh_L, calf_L, thigh_R, calf_R | 1 | 0 |
| 21–24 | 腿角速度 rad/s：thigh_L, calf_L, thigh_R, calf_R | 0.05 | 0 |

- **IMU 座標**：模擬裡 IMU 相對 `base_link_root` 位於 (−8.36, 0, −29.43) mm，旋轉為繞 x 軸 +90°（quat wxyz = 0.7071, 0.7071, 0, 0）。換算後 IMU x = 機身前方、y = 上方、z = 機身右方，所以直立時重力讀值為 (0, −1, 0)，pitch 角速度在 z 軸。實機 IMU 的安裝方向不同時，要先轉到這個座標再餵進去。
- **標稱腿角**：thigh = −0.50 rad、calf = +0.87 rad（兩側相同）。
- **命令範圍**（訓練範圍）：vx ∈ [−0.6, 0.6] m/s、yaw rate ∈ [−1.0, 1.0] rad/s、vy 永遠 0。超出範圍沒有訓練過。
- 訓練時對感測值加了均勻雜訊：重力 ±0.02、陀螺儀 ±0.05 rad/s、輪速 ±0.2 rad/s、腿角 ±0.01 rad、腿速 ±0.2 rad/s。

## 輸出 `actions`：float32 [1, 6]

**先 clip 到 [−1, 1]**（訓練時由環境 clip，模型本身不做），再換算：

| index | 關節 | 換算 | 馬達模式 |
|---|---|---|---|
| 0 | thigh_L | 目標角 = −0.50 + 0.25 × a | DM-J4310 位置模式，Kp 20、Kd 0.2，扭力上限 12.5 N·m |
| 1 | calf_L | 目標角 = +0.87 + 0.25 × a | 同上 |
| 2 | thigh_R | 目標角 = −0.50 + 0.25 × a | 同上 |
| 3 | calf_R | 目標角 = +0.87 + 0.25 × a | 同上 |
| 4 | wheel_L | 目標輪速 = 52.36 × a rad/s | DM-H3510 速度模式，Kd 4（Kp 0），扭力上限 0.45 N·m |
| 5 | wheel_R | 目標輪速 = 52.36 × a rad/s | 同上 |

clip 後的 action 同時要存下來，當下一步 obs 的 index 11–16。

## 每一步的流程（50 Hz）

```
讀 IMU、編碼器 → 組 obs（上表順序與 scale）→ policy → clip [-1,1]
→ 換算成腿目標角 / 輪目標速度送給馬達 → 存 action 給下一步
```

## 模擬驗收（`scripts/wheel_only/evaluate_walk.py`，標稱物理、無雜訊）

| 段落 | 命令 | 實際 | 最大 pitch |
|---|---|---|---|
| 站著 | 0 | −0.002 m/s | 0.5° |
| 前進 | 0.3 / 0.6 m/s | 0.297 / 0.597 | 5.2° / 5.4° |
| 後退 | −0.3 m/s | −0.299 | **11.0°** |
| 原地轉 | +1.0 / −0.5 rad/s | +1.016 / −0.514 | 5.7° / 0.8° |
| 邊走邊轉 | 0.4 m/s、+0.5 rad/s | 0.395、+0.512 | 6.9° |
| 停下 | 0 | 2 mm/s | 6.0° |

全程不倒，左右腿差 0.018 rad。完整數字在 `walk_summary.json`，影片 `play_walk.mp4`。

## 上實機前要注意

- **後退時 pitch 最大 11°**，離模擬的失敗判定 15° 只剩 4°，是餘裕最小的動作。第一次測試先用慢速檔。
- **實機馬達、IMU 的延遲，以及摩擦和質量的差異，都還沒驗證過**。訓練有隨機化：摩擦 0.6–1.0、機身 −0.15 / +0.25 kg、推力 ±0.8 m/s，但沒有模擬延遲。
- **IMU 安裝方向和關節正負號要逐一對過**。可以在模擬和實機上把機身往前傾，比對 obs 0–2 和 3–5 的正負號是否一致。
- 第一次上機建議架高、輪子懸空，先確認腿的目標角和輪子的轉向都正確，再放到地上。

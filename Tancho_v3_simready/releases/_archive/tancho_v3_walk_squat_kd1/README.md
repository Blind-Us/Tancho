# Tancho V3：WASD 走 + 收左腳 / 收右腳 / 蹲下 + 停下原地保持（輪 Kd 1）

**2026-11-22 的建議試玩 / 部署版。** 以 r16_400 為起點，在同一個 policy 裡加上速度追蹤：前進後退 ±0.6 m/s、轉向 ±1 rad/s（teleop 一到三檔）。放開按鍵後，原地用輪里程停住。沒有跳。

## 跟 r16_400 一樣的部分

34 維輸入、6 維輸出、輪馬達 kd = 1.0、抬腳表、蹲下偏移與 0.3 s 蹲下冷卻規則，見 `../tancho_v3_squat_kd1_r16_400/DEPLOY.md`。

## 不一樣的兩點

1. **obs 6–8 是真的速度命令**：(vx, 0, yaw rate)，範圍 vx ±0.6 m/s、yaw ±1 rad/s。
2. **輪里程（obs 29–30）的保持點**：只要命令不是 0（|vx| > 0.05 或 |yaw| > 0.05），每一步都把 `q_hold` 設成目前的輪角，所以開車時這兩個值是 0。命令歸零後 `q_hold` 就固定，量的是從停下那一點開始漂了多遠。
